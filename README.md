# Jian Liang — academic homepage

Static site for [jianliang22.github.io](https://jianliang22.github.io/).

The site is plain HTML and CSS, so GitHub Pages can publish the repository
root directly without a build step. It includes the current CV and portrait.
Edit `index.html` and `academic-20261023b.css` to update the page. When changing
the layout substantially, publish the CSS under a new filename and update the
link in `index.html` so visitors cannot see stale cached styles.
